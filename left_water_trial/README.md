# 왼쪽 T200 저속 전진·중립 수조 시험

대상은 CH0의 왼쪽 T200 한 대다. 오른쪽 ESC는 추진 전원과 신호를 모두 분리한다. 28.437 MHz 보정, PRESCALE 0x8A, CH0 307~315카운트, CH1~15 FULL OFF, 모터 기동 기준 최대 20초를 사용한다.

## 전원과 승인

현재 XT90은 추진 전원이 꺼진 상태에서 분리·격리하는 연결점으로 취급한다. 부하 개방은 해당 배터리 DC 전압과 예상 부하 전류에서 개방 정격이 확인된 독립 차단기로 수행한다. 추진 전원만 끊어도 Pi·RC 수신기·기록이 유지되는 배선과 수조 밖에서 차단기를 즉시 조작할 담당자가 필요하다. 추진기와 케이블을 고정하고 수조 및 회전체에 손이 닿지 않게 한다.

실행 전 승인 기록에는 이 구성의 ESC 사양, OE 기본 차단, Pi 정지·전원 상실을 포함한 독립 정지 동작, ESC 신호 상실 정지와 복구 시 재기동 방지의 실측 근거가 필요하다. 수동 차단기 확보만으로 Pi 정지 시 자동 차단이 입증되지는 않는다. 이 항목은 기존 네 실물 승인 조건을 그대로 사용한다. 승인된 별도 프로파일은 시험 범위(left_t200_water), 승인된 차단기 모델(propulsion_disconnect_model), 현장 승인 기록 참조(approval_record)가 있어야 한다. 프로그램은 프로파일 선언을 검사한다. 차단기 정격·설치 상태·증거의 진위는 현장 승인 대상이다. 저장소의 후보는 미승인 상태다.

## 실행

작업공간에서 ROS 환경을 준비한다.

```bash
cd ~/kaboat_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
/usr/bin/python3 left_water_trial/run.py
```

기본 동작은 장치 없는 프로파일 검사다. 현재 후보가 종료코드 2로 거부되는 것이 정상이다. 다음 경로는 현장에서 발행할 승인본의 예시다. 설치 확인과 분리된 오른쪽 ESC, 독립 차단 담당자, 수중 고정이 준비된 뒤에만 실행한다.

```bash
/usr/bin/python3 left_water_trial/run.py --profile ~/approved/left_t200_water.json --run
```

1. SB MANUAL, SA KILL, 스틱 중앙. ESC 추진 전원 투입은 담당자가 통제한다. 현장 확인 후 모터 터미널에 LEFT WATER를 입력한다.
2. 모터 상태가 발행되고 RC·링크가 정상인 상태에서 중앙·SA KILL을 최소 1초 유지한 뒤 SA를 허용한다. 조향은 계속 중앙에 둔다.
3. 왼쪽 ESC 초기화 2음, 실제 정지, armed=true 및 neutral_init_complete=true를 확인한 뒤 스로틀만 천천히 전진한다. 최초 회전 확인 즉시 중앙으로 복귀한다. 중립 307 되읽기와 실제 회전 정지를 별도로 기록한다. 제한 시간 안에 준비되지 않으면 회차를 끝낸다.
4. SA KILL 후 독립 차단기로 추진 전원을 끈다. 예상 밖 회전·중립 정지 실패·제어 중단 시 담당자가 즉시 독립 전원을 차단한다. 조작은 안전 거리에서 수행한다.

실행기는 새 results 디렉터리에 수신기·제어기 로그 및 ROS 로그를 저장한다. 실제 회전·정지는 관찰자가 기록한다. 출력 카운트와 OE 요청값은 전압이나 추력의 실측값이 아니다.
