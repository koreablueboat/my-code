# RC 보트 작업 일지

## 2026년 11월 24일 제어 개선 반영

[v002](improvements/v002_2026-11-24_163312_KST_control.md)에 모터 단절 처리, 양방향 프로파일, 벤치 측정표, 자동 시험과 토픽 안내를 기록했다. 소프트웨어 시험 40개가 통과했다. 다음 현장 작업은 ESC 사양 확인과 정지 시간 실측이다.

## 2026년 11월 24일 개선안 첫 버전 저장

제어 경로 검토에서 도출한 다섯 개선안과 확인 기준을 [v001](improvements/v001_2026-11-24_161922_KST_control.md)로 저장하고 기록 색인에 추가했다.

## 2026년 11월 24일 제어 경로 점검과 개발 기록 정리

- 세 ROS 패키지를 임시 경로에 새로 빌드하고 모터 단위시험과 합성 RC 통합시험을 실행했다. 명령 단절 후 콜백 순서에 따른 출력과 제자리 회전 시 두 제어기의 목표값을 비교했다.
- [검토 기록](reviews/2026-11-24-control.md)에 결과와 후속 작업 다섯 건을 정리했다. 통합시험 전체 실행 로그와 AUTO 재시험 로그를 함께 보관했다.
- [기록 색인](README.md)과 이 작업 일지를 만들었다. 다음 작업은 모터 명령이 0.5초 넘게 끊긴 뒤 새 명령이 먼저 도착하는 경우의 회귀시험과 수정이다.
