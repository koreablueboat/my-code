새 검토는 `reviews/YYYY-MM-DD-주제.md`에 저장하고 위 표에 연결한다. 검토에는 관찰한 동작, 근거, 개선안과 확인 기준을 남긴다. 보존할 시험 로그는 `reviews/evidence/YYYY-MM-DD/`에 둔다.

실제 작업을 마치면 작업 일지 맨 위에 날짜와 작업명을 추가하고, 변경한 파일, 실행한 검사와 결과, 남은 일을 기록한다. 검토에서 제안한 수정을 구현하면 해당 검토를 작업 항목에 연결한다.
