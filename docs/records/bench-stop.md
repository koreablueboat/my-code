# RC 단절과 Pi 정지 벤치 측정

현재 상태는 실물 측정 대기다. 추진 전원을 분리하고 수신기, 제어 전원과 계측기만 연결한다. 실제 ESC 모델과 보드 배선, 펌웨어, 예상 차단 시간의 근거를 측정 전에 기록한다. 출력 차단 시간은 Pi 밖의 계측기로 사건 발생부터 OE와 두 PWM 신호가 안전 상태에 도달할 때까지 측정한다.

| 시험 | 관찰 방법 | 판정 기준 | 실측과 판정 |
|---|---|---|---|
| 송신기 단절 및 복구 | 실제 수신기와 PREVIEW에서 송신기를 끄고 RC 프레임·LQ·estop·모터 상태 시각을 기록한 뒤 켠다. | 단절 시 정지하고 링크 복구 후에도 의도적인 중립·재무장 전까지 출력이 0이다. | 대기 |
| Pi 제어 프로세스 정지 | 독립 차단 회로와 제조사 사양을 확인한 벤치에서 모터 프로세스를 일시 정지한다. 외부 계측기로 OE 및 CH0/CH1을 연속 관찰한다. | 외부 차단기가 사전에 정한 허용 시간 내 동작하고 프로세스 재개만으로 출력이 재개되지 않는다. | 대기 |
| Pi 전원 상실 및 복구 | 제어 전원만 끊었다가 복구하며 외부 계측기로 OE와 PWM을 관찰한다. | 정지·재부팅 중 출력이 차단되고 명시적 재무장까지 차단 상태를 유지한다. | 대기 |

기록할 값은 시험 시각, 장비·프로파일, 고장 발생 시각, 마지막 RC 및 LQ, OE와 좌우 PWM 변화 시각, 복구 후 무장 상태, 파형 파일과 판정이다. RF PREVIEW 시험과 PCA 출력 시험의 결과를 각각 적는다. 현재 통합 제어기는 PREVIEW 전용이다. 실제 ESC의 신호 상실 반응과 추진 전원 차단 성능은 별도로 실측한다.
