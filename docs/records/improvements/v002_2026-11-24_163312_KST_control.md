# RC 보트 제어 개선 반영 v002

2026-11-24 16:33:12 KST에 기록했다. [v001 검토안](v001_2026-11-24_161922_KST_control.md)의 소프트웨어 변경과 모의 검증을 마쳤다. 실제 ESC 사양 확정과 벤치 측정은 대기 중이다.

1. **명령 단절**을 두 모터 코어의 수신 콜백에서도 검사한다. 0.79초 단절 뒤 명령이 타이머보다 먼저 도착하는 회귀시험은 수정 전 두 코어에서 실패했다. 수정 후 콜백 순서와 관계없이 무장을 해제하고 새 중립 명령과 재무장을 요구하는 것을 확인했다.
2. **양방향 추진기**는 두 백엔드에서 같은 제어기를 사용한다. 실물 프로파일에는 후진 출력 상한과 방향 전환 중립 시간을 명시해야 한다. 모의 PCA에서 상한 0.02와 중립 0.60초를 적용해 좌우 PWM을 확인했다. 두 수치는 시험 입력이다.
3. **실물 정지 검증**을 위한 [벤치 측정표](../bench-stop.md)를 추가했다. 이 환경에는 수신기 UART, I²C 및 GPIO 장치가 없어 RF 단절, Pi 정지, 출력 차단 시간과 복구 상태는 실측 대기다.
4. **자동 시험**을 colcon에 등록했다. 통합시험은 활성 설치 경로에서 실행 파일을 찾는다. 별도 설치 경로에서도 세 실행 파일의 위치와 재무장 상태 확인 시험을 검증했다. AUTO 전이 로그에 사유와 마지막 수신 시각을 추가했다. 기존 간헐 실패의 원인은 미확정이다.
5. **에이전트 연결**은 [워크스페이스 안내](../../../README.md)와 제어·모터 README에 반영했다. 에이전트는 `/boat/auto/cmd_vel`에 후보를 발행하고 제어기가 `/boat/cmd_vel`을 단독 발행한다.
